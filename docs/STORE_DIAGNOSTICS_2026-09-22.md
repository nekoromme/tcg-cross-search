# 店舗別の「未確認」原因調査と修正

前回の15商品点検後、未確認表示の原因を店舗の検索フォーム・公開HTML・商品ページと照合した。
「候補なし」をすべて未確認に数えていたため、前回の説明は取得失敗と該当なしを混同していた。

## 原因と対応

| 対象 | 実証した原因 | 対応 |
|---|---|---|
| CARDMAX | 生HTMLの引用符なしhrefを読めず、検索結果のBOXを落としていた。商品名もh2#M_itemNameで未対応 | リンク解析と商品見出し判定を修正。GD04の5,808円・売切を修正版の実検索で確認 |
| CBトレコロ | keywordだけでは検索フォームが表示され、検索を実行しない | 店のフォームにあるsearch=xを追加。実ページのページ送りp/psにも対応 |
| サンズ（Yahoo!ショッピング） | FB11の商品名がh1ではなく専用p。本文の在庫確認開始点がなかった。ポイントの「税抜価格が対象」という注意書きも商品価格の税区分と誤認していた | 専用の商品名・価格・在庫領域を認識。他ストアの在庫やポイントの注意書きは混ぜない |
| メディアワールド | LA-OP17というフィギュア用品がワンピースの要確認候補に混入 | フィギュア用品を除外 |
| WiZ・トレカ侍・マスターズ1号・アドバンテージ2号・パピー等 | 店舗の検索0件を抽出失敗と同じ扱いにしていた | 店舗が明示した空結果のみ、確認範囲で該当なしとして分離 |
| アドバンテージ GD04カートン | 商品ページ自体が販売価格0円・在庫なし | 0円を販売価格にせず、店舗の0円表示が理由だと明示 |
| Day屋 GD04 | ブラウザーでも検索本文が空、0件の明示もなし | 該当なしと断定せず未確認を維持。空category_id追加でも同じことを公開HTTPで検証し、効果のない修正は入れなかった |

## 共通の改善

- 商品URLの引数を全消去して重複判定する処理を修正。brandcode等に商品番号を持つ別商品を潰さない。
- URLにだけ個別カード番号を載せる店でも、シングル除外の根拠を記録。URLだけでBOXとして採用しない。
- 正常な0件、途中まで確認、通信失敗を別に表示。0件は売切れを意味しない。
- 詳細のHTTPエラー、タイムアウト、商品名・価格・在庫の読み取り不明をログと応答に保存。ログへ検索語・Cookie・認証情報を出さない。
- 先頭ページ、詳細最大4件、時間・通信上限は維持。「広く探す」は最大3ページ。検索全件や全店舗を網羅したという意味にはしない。

## 検証

- 84自動テスト成功。実際の引用符なしリンク、別商品IDの維持、Yahoo商品領域、0件の誤認防止、別商品除外、詳細失敗理由を含む。
- 公開HTTPの生HTMLでCARDMAX不具合を再現し、修正後にGD04のBOX候補抽出を確認。
- 修正版の画面でGD04は4→5掲載（CARDMAX追加）。ニンジャスピナー、OP17、FB11も再検索。
- 診断用スクリプト scripts/diagnose-stores.mjs は手動実行用。通常のテストや定期監視では外部店舗へ通信しない。
